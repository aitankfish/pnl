This is the developer-facing documentation for PNL (Predict & Launch) — the conviction-market launchpad on Solana. The docs are written to be read in order from start to finish. Each chapter is short enough to read in one sitting; together they cover the protocol, the economics, the integration surfaces, and the operating posture with no implicit knowledge required.

If you only have ten minutes, start with the [manifesto](/docs/manifesto) — it stakes the thesis behind why this exists.

If you want to participate, [how to buy](/docs/how-to-buy) walks you through getting a wallet and your first stake.

If you're building, [the quickstart](/docs/build/quickstart) has working code samples for reading state, voting, and creating markets — copy-pasteable, no SDK required.
